# Apex PvP

## Principle

PvP must not reward genetics or raw strength alone.

It should reward:

- consistency;
- personal improvement;
- effort relative to ability;
- recovery;
- hydration;
- nutrition;
- safe adherence;
- teamwork;
- healthy long-term habits.

## Fairness

Apex acts as a fairness engine so beginners, advanced athletes, older adults, and disabled users can all contribute meaningfully.

## Rules

- No pay-to-win.
- No unsafe overtraining incentives.
- Recovery must remain valuable.
- Scoring must be explainable.
- Anti-cheat should use evidence without unfairly excluding accessibility needs.
