# Apex Checkpoint Checklist

Before creating a checkpoint:

- [ ] Dedicated tests pass
- [ ] `npm run apex:quick` passes
- [ ] `npm run docs:check` passes
- [ ] `git diff --check` passes
- [ ] `PROJECT_STATUS.md` is current
- [ ] `docs/build-log/current.md` is current
- [ ] Roadmap updated if scope changed
- [ ] Architecture documents updated if contracts changed
- [ ] Release notes updated for meaningful milestones
- [ ] No secrets or environment files are staged
- [ ] Commit is pushed to the correct branch
