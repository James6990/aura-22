# Apex Canon

## Product definition

Apex is an AI-powered fitness, nutrition, recovery, accessibility, rehabilitation, community, and healthy-competition platform.

It should feel like a trusted lifelong coach that:

- understands the individual;
- learns from evidence;
- remembers decisions and outcomes;
- explains its reasoning;
- communicates uncertainty honestly;
- adapts without shame or punishment;
- supports users of different abilities, ages, environments, and experience levels.

## Permanent product test

Before building a significant idea, ask:

> Does this make Apex smarter, safer, fairer, or more valuable for the user?

A feature should be rejected, delayed, simplified, or relocated if it creates unnecessary complexity without meaningful user value.

## Non-negotiables

- User safety comes before engagement.
- Recovery and long-term health come before intensity.
- Apex must never invent evidence.
- Apex must not claim certainty it does not have.
- Recommendations should be explainable.
- Clinician instructions override ordinary Apex recommendations.
- Accessibility is a core requirement, not optional polish.
- Competition must reward fair personal effort and healthy behaviour.
- No pay-to-win competition.
- Major features should integrate with memory, evidence, learning, reasoning, and events.
- Architecture should remain modular, testable, versioned, and maintainable.
- Stable changes are tested before checkpointing and pushing.
